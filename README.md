# Sistema de Almoxarifado

Sistema de controle de almoxarifado desenvolvido em PHP para gestão de estoque.

## 📌 Descrição

O sistema permite o gerenciamento de produtos e controle de estoque de forma simples e eficiente, garantindo maior organização e precisão nas movimentações.

## 🚀 Funcionalidades

- Cadastro de produtos  
- Controle de entradas e saídas  
- Atualização automática do saldo em estoque  
- Controle de acesso por usuários  
- Rastreamento de operações realizadas  

## 🛠️ Tecnologias utilizadas

- PHP  
- MySQL
- CSS  

## 📄 Objetivo

Facilitar o controle de estoque, evitando erros como retirada de produtos inexistentes e falta de rastreabilidade das operações.
